Generated on 2026-10-15 using the built-in imagegen tool, then copied into the
canonical Portal public asset directory. These illustrations establish context;
they do not supply assessment data, depict verified medical findings or define
causal relationships. The application renders all numerical tables and graphs.

Files: `effect-general.png`, `effect-medical.png`, `shift-general.png`,
`shift-medical.png`. Each is an opaque 3:2 editorial illustration.
